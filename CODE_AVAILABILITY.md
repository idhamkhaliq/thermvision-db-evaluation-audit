# Code and reproducibility availability

The public reproducibility repository for the manuscript **Protocol Sensitivity in Synthetic Thermal Video Face Recognition: An Evaluation Audit of ThermVision-DB** is available at:

- GitHub: https://github.com/idhamkhaliq/thermvision-db-evaluation-audit
- Archived release: v0.1.0
- Zenodo DOI: https://doi.org/10.5281/zenodo.22974338

The release contains verification scripts, frozen derived result exports, and provenance records. It does not redistribute raw ThermVision-DB media, pretrained ArcFace/AdaFace model weights, or the original execution notebooks whose hashes are documented in the provenance record.
