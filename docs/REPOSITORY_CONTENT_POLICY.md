# Repository content policy

This repository intentionally excludes:

1. raw ThermVision-DB media;
2. any access tokens or private credentials;
3. pretrained model weight files (`.onnx`, `.pt`, `.pth`, `.ckpt`);
4. contact-sheet images containing dataset frames;
5. superseded exploratory artifacts that are not part of the final manuscript evidence chain.

The included files are derived tabular/JSON outputs, frozen lock/configuration records, and lightweight verification scripts.
